# MRAgent 核心创新可信度评估

## 1. 评估问题

本轮分别判断两个命题：

1. 图结构是否比平面记忆表示更有效。
2. 在相同图视图上，多轮主动搜索是否比一次性被动读取更有效。

所有数值均来自服务器现存 JSONL，并使用仓库官方 eval/evaluation.py 的 F1 重新计算。置信区间以 conversation 为 cluster 做 20,000 次配对 bootstrap。

## 2. 500 题主实验

| 方法 | 普通题 F1 | 相对修复版 MRAgent 差值 | 95% CI |
|---|---:|---:|---:|
| 修复版 MRAgent | 0.5450 | - | - |
| RAG | 0.3102 | +0.2349 | [0.1943, 0.2831] |
| 简化 GraphRAG | 0.3125 | +0.2325 | [0.1972, 0.2786] |

主效果稳定，但这个对比同时改变图结构、主动工具循环、上下文规模和计算预算，不能单独证明其中任一机制。

## 4. 88 个 Judge WRONG 的证据

- 88/88 的 gold turn 都存在于 rewrite/episode 表示。
- 59/88 完全没有把 gold evidence 带入最终上下文。
- 18/88 只带入部分 gold evidence。
- 11/88 完整带入 gold evidence。
- 54 题归因为主动检索路径失败，18 题为部分检索后回答不完整。
- 另有 5 个时间推理错误、3 个多跳组合错误、1 个答案生成错误、4 个执行或 schema 错误。
- 发现 2 个高置信 Judge false negative 候选和 1 个 gold annotation error。
- 88/88 均保存了 raw prompt、raw response 和工具轨迹，共对齐 846 组请求与响应，无歧义匹配。

行为对比：

| 指标 | Judge CORRECT 312 题 | Judge WRONG 88 题 |
|---|---:|---:|
| 平均工具调用 | 6.10 | 12.85 |
| 平均搜索轮数 | 4.17 | 6.65 |
| 跑满 8 轮 | 28 | 56 |
| gold 全覆盖 | 218 | 11 |
| gold 零覆盖 | 28 | 59 |

WRONG 题调用更多工具并更常耗尽 8 轮，说明失败通常不是过早 Finish，而是路径选择低效、重复探索或无法把线索转成正确的下一跳。

## 5. 最终判断

| 核心命题 | 当前结论 | 可信度 |
|---|---|---|
| 原始对话内容被建入事件图 | 88 个错题的 gold turn 均存在 | 强 |
| 图结构整体优于平面 RAG | 主实验差值稳定，但混合主动搜索和预算差异 | 中等 |
| tag 层独立有效 | CTE passive 不优于 CE passive | 未成立 |
| topic/person 内容层有效 | passive 下稳定为正，但上下文 token 未匹配 | 部分成立 |
| 主动搜索有效 | CTE、CTC 两种图视图均稳定优于 passive，修复前后都成立 | 强 |
| CTC 内容工具在 active 下继续增益 | 相对 CTE active 的 CI 跨 0 | 未成立 |
| 当前主动路径已经足够好 | 72/88 判错存在完全或部分检索失败 | 否 |

因此，当前最严格的表述是：

> MRAgent 的主动搜索机制已有较强、可重复的实验支持；图结构提供了有效的信息组织基础，但并非所有图层都已证明有独立贡献。图结构的最终因果结论仍需要 token/context 预算匹配，以及和更强、设置对齐的图检索基线比较。

## 6. 后续实验要求

1. 外部 baseline 完成后统一运行 V4-Flash Judge。
2. 用 repaired-v3 的 400 道普通题重新生成 WRONG 审计。
3. 对 54 个路径失败题提取首个错误动作、重复状态、无效工具和预算耗尽位置。
4. 设计相同上下文 token、相同调用预算的 CTE/CTC/RAG 对照。
5. Q-learning 优先学习下一跳工具与停止策略，并同时约束正确率、证据覆盖、调用次数和延迟。
