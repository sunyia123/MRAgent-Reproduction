# Standard RAG Baseline — 2026-07-02

## 1. Purpose

Implement a standard RAG (Retrieval-Augmented Generation) baseline as a comparison
point for MRAgent's graph-memory tool-calling approach.

This baseline:
- Reuses MRAgent's rewrite sentences as the retrieval corpus
- Reuses the same embedding model and question embeddings
- Retrieves top-k sentences by cosine similarity
- Sends context + question to the same QA model in a single turn (no tool calling)
- Outputs prediction JSONL compatible with `eval/evaluate_reasoning.py`

## 2. Implementation

**Script**: `repro/run_standard_rag_baseline.py`

### Design

```
1. Load rewrite JSONL → extract all sentences (sentence_id, text, origin, tag)
2. Load embedding pkl → get sentence embeddings + question embeddings
3. For each question:
   a. Get question embedding (from pre-computed embedding pkl)
   b. Compute cosine similarity with all sentence embeddings
   c. Take top-k sentences
   d. Build context string from top-k sentences
   e. Send context + question to LLM in a single turn
   f. Write prediction JSONL
```

### Key differences from MRAgent

| Aspect | MRAgent | RAG Baseline |
|--------|---------|-------------|
| Retrieval | Graph traversal + keyword + tag + topic | Top-k embedding similarity |
| Reasoning | Multi-round tool-calling (4-8 rounds) | Single-turn QA |
| Memory | KeyNode, EpisodeEvent, Topic, Persona graph | Flat sentence list |
| Context | query_conversation_time, query_event_context | Raw top-k sentences |
| Evidence | Supports from tool trace | Top-k sentence origins |

### Parameters

- `--top_k`: Number of sentences to retrieve (default 20)
- `--data`: Dataset (locomo / LM)
- `--model`: Model short name
- `--file`: Run tag
- `--sample_ids`: Comma-separated sample IDs
- `--max_samples`: Max sample count

## 3. Usage

```bash
# Smoke test (conv-30 only)
python repro/run_standard_rag_baseline.py \
  --data locomo --model deepseek --file rag_smoke \
  --sample_ids 30 --top_k 20

# Explore-50 baseline (5 samples)
python repro/run_standard_rag_baseline.py \
  --data locomo --model deepseek --file rag_explore50 \
  --sample_ids 30,42,44,48,50 --top_k 20

# Full LoCoMo-10 baseline
python repro/run_standard_rag_baseline.py \
  --data locomo --model deepseek --file rag_locomo10 \
  --top_k 20

# Evaluate (same script as MRAgent)
python eval/evaluate_reasoning.py \
  --data locomo --model deepseek --file rag_explore50 --allfile
```
